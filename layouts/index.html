01About

Engineer by training,
builder by instinct.

I'm finishing my Matura in Electrical Engineering with a focus on Robotics at HTBLUVA Salzburg. My work spans the full stack of embedded systems — from schematic capture and PCB layout all the way to firmware and control algorithms.

My diploma thesis, ALBERT, is a custom flight computer for a fin-controlled model rocket using LQR state-feedback control. It's the kind of project where everything has to work together: hardware, software, and math.

Hardware PCB design, schematic, layout, bring-up, embedded hardware
Software C, Python, MATLAB / Simulink
Theory Control theory, LQR, state-space modelling, Kalman filters
Languages German (native), English (C2 — Cambridge CPE)
